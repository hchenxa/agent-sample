Available Commands:
- `/new-chat`: Start a new chat session.

- **Jenkins Commands** (if configured):
  - **Job Management:**
    - `/jenkins list jobs [related to <keyword>]` or `list jenkins jobs`
    - `/jenkins list views` or `list jenkins views`
    - `/jenkins check job <job_name>` or `check jenkins job <job_name>`
    - `/jenkins trigger job <job_name> [with params param1=value1,param2=value2]`
    - `/jenkins health` or `health check` - Comprehensive health report with charts

- **ReportPortal Commands** (if configured):
  - `/rp list launches [attribute_key=attribute_value]`
  - Natural language queries like "test report for component=<name>"

- **Jira Commands** (if configured):
  - `/jira query <natural_language_query>`
    Example: `/jira query globalhub bugs to be fixed in current release`
  - `/jira whoami` - Get information about current Jira user

- **General Chat**: Any other query will be handled by the selected LLM (Models.corp or Ollama).
